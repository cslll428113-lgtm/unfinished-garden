# 未完之境 · 自由花园

**一座未完成的建筑，一座由你自由布置的花园。**

以“烂尾楼被自然重新占据”为主题的环境设计课程互动作品。玩家可以围绕一层庭院与二层露台自由种植，调整植物的位置、体量与朝向，探索混凝土建筑和自然生长之间的关系。

[在线体验](https://unfinished-garden-shuluo.mbtxrn2zkd.chatgpt.site/)

> 当前在线体验使用 ChatGPT Sites 托管，部分网络环境的可达性尚未验证。本仓库包含完整静态网站，可独立部署。

![自由花园实机画面](docs/preview.png)

## 可以做什么

- 自由旋转、缩放和平移三维视角。
- 在两层楼面的任意有效位置种植，无固定坑位和回合次数限制。
- 12 种植物：榕树、青枫、银杏、三角梅、绣球、蓝花鼠尾草、肾蕨、龟背竹、玉簪、细叶芒、常春藤、绿萝。
- 拖动、缩放、转向、复制或移除植物，支持撤销与重做。
- 切换楼层视图、午后与暮色，触发雨景和植物生长。
- 保存当前视角的 PNG 风景图；植物布局自动保存在当前浏览器。
- 提供示范花园，也可以清空后从零创作。

## 本地运行

需要安装 Node.js 18 或更新版本。下载或克隆仓库，在项目目录运行：

```bash
npm start
```

浏览器打开终端显示的 `http://localhost:5173`。运行所需的 Three.js 文件已经随项目保存在 `dist/vendor/`，无需先安装依赖，也无需连接外部 CDN。由于项目使用 JavaScript 模块，请使用上面的本地服务，不要直接双击 HTML 文件。

可选的 JavaScript 语法检查：

```bash
npm run check
```

## 操作

| 操作 | 方法 |
| --- | --- |
| 种植 | 点击右侧植物卡片，再点击楼面；可连续种植 |
| 移动植物 | 切换“选择 / 移动”，拖动植物 |
| 大小与朝向 | 选中植物后使用右侧滑杆 |
| 旋转视角 | 拖动空白处，或点击底部旋转按钮 |
| 缩放 | 鼠标滚轮，或底部加减按钮 |
| 平移 | 鼠标右键拖动 |
| 退出种植 | `Esc`，或点击“浏览” |
| 选择工具 | `V` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z`，Mac 可用 Command |
| 删除选中植物 | `Delete` 或 `Backspace` |
| 导出图片 | 右上角“保存风景”，通过浏览器下载 PNG |

## 部署

这是纯静态网站，无后台、数据库或密钥。将 **`dist/` 目录中的全部文件**上传到支持静态网站的托管服务即可，保留目录结构。

- 构建命令：无需构建。
- 发布目录：`dist`。
- 网站入口：`dist/index.html`。
- 运行时依赖：随站点提供，无外部字体或第三方资源请求。

本仓库上传到 GitHub 与在线站点部署是两个独立步骤；仅推送代码不会自动更新现有的 ChatGPT Sites 站点。后续可在选定的托管平台配置 GitHub 自动部署。

## 项目结构

```text
dist/
  index.html             页面与界面结构
  style.css              布局、配色与响应式样式
  game.js                三维场景、植物、交互与存档
  canvas-renderer.js      不支持 WebGL 时的兼容渲染
  vendor/                Three.js、OrbitControls 与许可文件
scripts/serve.mjs         无额外依赖的本地预览服务
docs/preview.png          实机截图
```

## 保存与限制

- 花园布局保存于当前浏览器的 localStorage，不会跨设备同步；清除网站数据可能删除存档。
- PNG 是当前风景的图片，不是可重新导入编辑的花园存档。
- 同时最多放置 110 株植物，以控制渲染负担。
- 优先使用 WebGL 2 渲染；不支持时使用 Canvas 兼容模式。两种模式的光影与遮挡细节可能不同。
- 已在兼容模式实测种植、拖动、大小与转向调整、复制、删除、撤销重做、楼层切换、视角旋转、刷新恢复存档和 PNG 导出。硬件加速光影未在制作环境实测；移动端实机测试尚未完成。
- 植物生长与建筑构造是环境设计概念表达，不作为实际施工依据。
